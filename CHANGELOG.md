# Changelog

## [1.0.1] - 2026-10-25

### Исправлено

- `migrate` переводит на `me` и плательщика у дохода (схема 1 его не замечала), а не отказывает в переводе; в отчёте такие записи названы по номерам.
- Копия журнала перед записью спрашивает git один раз на папку данных за запуск, а не на каждую запись.
- `check` при откате файлов, изменённых за время тестов расширений, прямо говорит, что отменено всё сделанное за время проверки, в том числе со страницы.
- `update`: если Ctrl+C пришло уже после замены кода, сообщение говорит, что обновление завершено и переименовывать ничего не нужно.

## [1.0.0] - 2026-10-25

### Added

- Общий код Бюджеведа: журнал, отчёты, импорт выписки Kaspi и страница-кабинет.
- Данные лежат в отдельной папке, путь к ней передаётся ключом `--data`.
- README с промптом первого запуска: агент проверяет Python и git, берёт код, создаёт папку данных и расспрашивает о деньгах.
- `scripts/smoke.py` проверяет первый запуск без git, в CI на Windows.
