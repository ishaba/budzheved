# Бюджевед

Учёт денег с агентом: общий код, а данные у каждого в своей папке. Журнал хранится
в CSV, команды и страница-кабинет работают поверх одной папки данных (`--data PATH`).

## Правила проекта

- Только стандартная библиотека Python, версия 3.11 и выше. Зависимости для
  разработки (ruff, pytest) стоят в `pyproject.toml` и в запуск не входят.
- Любое изменение идёт с тестом. Тесты запускаются командой
  `python -m unittest discover -s tests`, она работает без uv.
- Код должен работать на Windows: пути через `pathlib`, у каждого `open()` явный
  `encoding="utf-8"`, без модулей, которых нет в Windows.
- В коде, тестах, примерах и истории нет личных данных и внутренней
  инфраструктуры. Имена в тестах выдуманные: `anya`, `boris`, «Аня», «Борис».
- Код читает только папку данных и собственную папку.
- Тексты для человека по-русски, идентификаторы кода по-английски.
- Проверка перед коммитом: `./bin/verify` (ruff и pytest через uv).
- Коммиты: `type(scope): описание`. Тип и scope по-английски, описание по-русски
  в настоящем времени, до 72 символов, без точки.
